## Data & Energy

- [DC Hub](https://github.com/azmartone67/dchub-mcp-server) — DC Hub is the live data layer for data-center site selection and the power, grid and energy behind it. Its Data Center Power Index (DCPI) scores grid power for data centers in 300+ markets. 94 MCP tools, free to start. Endpoint: `https://dchub.cloud/mcp`
